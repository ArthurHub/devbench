# 12 CI for the client

Status: resolved
Blocked by: 02

Spec: [../spec.md](../spec.md).

## What

A GitHub Actions job that installs `clients/python` and runs its unit tests on changes under `clients/python/`.
Formatting and linting are ticket 01 (pre-commit).

- `.github/workflows/python-client.yaml`: push to main, PRs and dispatch, filtered to `clients/python/**` and the
  workflow itself. windows-2025 (the platform the client runs on), Python 3.10 (`requires-python`) and 3.x.
- Full clone, then the release tags fetched from rollingrock/devbench: the ArthurHub fork carries none, so the
  version tracks upstream's releases until ticket 17 settles the fork's scheme.
- A non-editable `pip install ./clients/python`, a step that fails on the `0.0.0` fallback, then `pytest -v`.

## Acceptance

The job runs and passes on a PR touching `clients/python/`; the version from setuptools-scm resolves in CI (needs the
tags fetched).

Checked locally (2026-11-15): the same steps in a fresh venv resolve `1.14.1.dev170+gdeb684949` and pass 181 tests; a
tagless clone of the fork gets 21 tags from the upstream fetch. Not yet run on GitHub.
